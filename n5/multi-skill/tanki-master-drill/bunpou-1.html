もんだい1 — what goes in the （　）?

（　　）に 何を 入れますか。１・２・３・４から いちばん いいものを 一つ えらんで ください。(  ) ni nani o iremasu ka. 1・2・3・4 kara ichiban ii mono o hitotsu erande kudasai.

EN: What do you put in the ( )? Choose the best one from 1–4.   HI: ( ) में क्या डालेंगे? 1–4 में से सबसे सही एक चुनें।   GU: ( ) માં શું મૂકશો? 1–4 માંથી સૌથી યોગ્ય એક પસંદ કરો.

もんだい1 Q1

えいがかん（　）どこに ありますか。Eigakan (  ) doko ni arimasu ka.

EN: Where is the cinema?
HI: सिनेमा हॉल कहाँ है?
GU: સિનેમા હૉલ ક્યાં છે?
OptionJapaneseEnglishHindiGujarati
1をoobject marker (for the thing you act on)कर्म चिह्न (जिस पर क्रिया हो)કર્મ ચિહ્ન (જેના પર ક્રિયા થાય)
2はwatopic marker ✓विषय चिह्नવિષય ચિહ્ન
3のno"of, 's" (joins two nouns)"का / की" (दो संज्ञाएँ जोड़ना)"નું / ની" (બે નામ જોડવા)
4にni"at, to" (place / time)"में, को" (जगह / समय)"માં, ને" (જગ્યા / સમય)

Why: We are asking about the cinema, so it is the topic: えいがかんは どこに ありますか. The place word どこ already has に. あります is not an action done to something, so を is wrong. の would need a noun after it.

もんだい1 Q2

クラスで（　）が あなたと おなじ たんじょうびですか。Kurasu de (  ) ga anata to onaji tanjoubi desu ka.

EN: Who in the class has the same birthday as you?
HI: क्लास में किसका जन्मदिन तुम्हारे जन्मदिन के दिन ही है?
GU: વર્ગમાં કોનો જન્મદિવસ તમારા જેવો જ છે?
OptionJapaneseEnglishHindiGujarati
1どこdokowhereकहाँક્યાં
2いつitsuwhenकबક્યારે
3なにnaniwhatक्याશું
4だれdarewho ✓कौनકોણ

Why: The answer must be a person in the class who shares your birthday ("あなたと おなじ"). A person = だれ. いつ ("when") is a trap because the sentence talks about a birthday, but the question is about a person, not a date.

もんだい1 Q3

あの 店は（　）安いです。Ano mise wa (  ) yasui desu.

EN: That shop is tasty and cheap.
HI: वह दुकान स्वादिष्ट भी है और सस्ती भी।

OptionJapaneseEnglishHindiGujarati
1おいしいoishiitasty (plain form, cannot join)स्वादिष्ट (सादा रूप, जोड़ नहीं सकता)સ્વાદિષ્ટ (સાદું રૂપ, જોડી ન શકાય)

EN: The town where I was born is a nice place, clean and quiet.

OptionJapaneseEnglishHindiGujarati
1きれいkireiclean / pretty (bare form)साफ़ / सुंदर (मूल रूप)સ્વચ્છ / સુંદર (મૂળ રૂપ)

HI: कमरे की मेज़ पर सुंदर फूल हैं।
GU: ઓરડાના ટેબલ પર સુંદર ફૂલ છે.
OptionJapaneseEnglishHindiGujarati
1が ありますga arimasuthere is (a thing) ✓(कोई चीज़) है(કોઈ વસ્તુ) છે

けさ わたしは あさごはんを（　）しごとに 行きました。Kesa watashi wa asagohan o (  ) shigoto ni ikimashita.

EN: This morning I went to work without eating breakfast.

OptionJapaneseEnglishHindiGujarati
1食べたtabetaate (cannot join two actions)खाया (दो काम जोड़ नहीं सकता)ખાધું (બે ક્રિયા જોડી ન શકે)

ごろ / ぐらいgoro / guraiaround / aboutごろ = a point on the clock or calendar. ぐらい = an amount or a length of time.
HI: ごろ = समय का बिंदु; ぐらい = मात्रा/अवधि. GU: ごろ = સમયનું બિંદુ; ぐらい = માત્રા/સમયગાળો.		7時ごろ (Q19)／1時間ぐらい
〜る前に / 〜たあとで~ru mae ni / ~ta ato debefore / after前に takes the dictionary form; あとで takes the た-form. The tense of the whole sentence does not change this.
HI: 前に + मूल रूप; あとで + た-रूप. GU: 前に + મૂળ રૂપ; あとで + た-રૂપ.		行く前に (Q11)／ねた あとで (Q12)
〜くて / 〜で~kute / ~de… and …い-adj → くて. な-adj → で. Watch out: きれい is a な-adjective.
HI: い-विशेषण → くて; な-विशेषण → で. GU: い-વિશેષણ → くて; な-વિશેષણ → で.		おいしくて 安い (Q3)／きれいで しずか (Q4)
〜く / 〜に + なる・する~ku / ~ni + naru / surubecome / makeい-adj → く (あかるく). な-adj → に (しずかに). Never あかるいに.
HI: い → く; な → に. GU: い → く; な → に.		あかるく なる (Q18)／はやく する (Q15)
〜て あります / 〜て おきます~te arimasu / ~te okimasuhas been done / do in advanceてある: describes the result you see now (N が). ておく: describes doing it for later (N を).
HI: てある = अभी दिखता परिणाम; ておく = पहले से तैयारी. GU: てある = હમણાં દેખાતું પરિણામ; ておく = અગાઉથી તૈયારી.		てがみが おいて あります (Q21)
〜ないで / 〜なくて~naide / ~nakutewithout / because notないで = "without doing" or "please don't". なくて = "because (it) is not…" (added, not in book; N4 level).
HI: ないで = बिना किए; なくて = न होने के कारण. GU: ないで = કર્યા વગર; なくて = ન હોવાથી.		食べないで 行く (Q6)／かえらないで ください (Q23)
Exam trap: many questions here (Q3, Q4, Q15, Q18, Q24) test only one thing: what comes right after the blank. Before a noun → plain form (〜い／〜な). Before another adjective → くて／で. Before a verb (なる, する, 書く) → く／に. Look at the word after the （　） first, then pick the form.
