もんだい3 文脈規定 — what goes in the ( )?

（　）に なにを いれますか。１・２・３・４から いちばん いいものを ひとつ えらんで ください。( ) ni nani o iremasu ka. 1・2・3・4 kara ichiban ii mono o hitotsu erande kudasai.

EN: What do you put in the ( )? Choose the best one from 1–4.   HI: ( ) में क्या डालेंगे? 1–4 में से सबसे सही एक चुनें।   GU: ( ) માં શું મૂકશો? 1–4 માંથી સૌથી યોગ્ય એક પસંદ કરો.

もんだい3 Q1

タクシーを（　）ください。Takushii o ( ) kudasai.

EN: Please ( ) a taxi.
HI: कृपया एक टैक्सी ( )।
GU: કૃપા કરીને ટેક્સી ( ).
OptionJapaneseEnglishHindiGujarati
1のってnotteride (のる)सवार होइए (のる)સવાર થાઓ (のる)
2よんでyondecall (よぶ) ✓बुलाइएબોલાવો
3とってtottetake, pick up (とる)लीजिए, उठाइए (とる)લો, ઉપાડો (とる)
4あってattemeet (あう)मिलिए (あう)મળો (あう)

Why: タクシーを よぶ = "call a taxi". のる would need に: タクシーに のって. Look at the particle を first, then the verb. よむ (read) also becomes よんで, but here it is よぶ (call).

もんだい3 Q2

いもうとは あかい ぼうしを（　）。Imouto wa akai boushi o ( ).

EN: My younger sister ( ) a red hat.
HI: मेरी छोटी बहन ने लाल टोपी ( )।
GU: મારી નાની બહેને લાલ ટોપી ( ).
OptionJapaneseEnglishHindiGujarati
1とっていますtotte imasuis takingले रही हैલઈ રહી છે
2きていますkite imasuis wearing (a shirt, a coat)(कपड़े) पहने है(કપડાં) પહેર્યાં છે
3かかっていますkakatte imasuis hangingटंगा हैલટકે છે
4かぶっていますkabutte imasuis wearing (a hat) ✓(टोपी) पहने है(ટોપી) પહેરી છે

Why: Japanese uses a different "wear" verb for each body part. On the head (hat): かぶる. On the body (shirt, coat): きる. On the feet (shoes, trousers): はく. So ぼうしを かぶっています.

HI: "अलविदा। कल ( ) मिलेंगे।"
GU: "આવજો. કાલે ( ) મળીશું."
OptionJapaneseEnglishHindiGujarati

もんだい3 Q5

わたしは あさ シャワーを（　）。Watashi wa asa shawaa o ( ).

EN: I ( ) a shower in the morning.
HI: मैं सुबह शावर ( )।
GU: હું સવારે શાવર ( ).
OptionJapaneseEnglishHindiGujarati
1はいりますhairimasuenterअंदर जाता हूँઅંદર જાઉં છું
2あびますabimasutake (a shower) ✓लेता हूँ (शावर)લઉં છું (શાવર)

Why: シャワーを あびる is the set phrase for a shower. A bath is different: おふろに はいる. That is why はいります is a trap, but it needs に and おふろ.

EN: ( ) do you study Japanese every day?
HI: आप हर दिन ( ) जापानी पढ़ते हैं?
GU: તમે દરરોજ ( ) જાપાની ભણો છો?
OptionJapaneseEnglishHindiGujarati
1どれくらいdore kuraihow long, how much ✓कितनी देरકેટલો સમય
2いくつikutsuhow many (things); how oldकितने; कितनी उम्रકેટલા; કેટલી ઉંમર

EN: I ( ) the bridge and go shopping.
HI: मैं पुल ( ) खरीदारी करने जाता हूँ।
GU: હું પુલ ( ) ખરીદી કરવા જાઉં છું.
OptionJapaneseEnglishHindiGujarati
1とってtottetakeलेकरલઈને

こばやしさんは すずきさんに ほんを かりました。Kobayashi-san wa Suzuki-san ni hon o karimashita.

EN: Kobayashi borrowed a book from Suzuki.
HI: कोबायाशी जी ने सुज़ुकी जी से किताब उधार ली।

OptionJapaneseEnglishHindiGujarati
1すずきさんは こばやしさんに ほんを かしました。Suzuki-san wa Kobayashi-san ni hon o kashimashita.Suzuki lent a book to Kobayashi. ✓सुज़ुकी जी ने कोबायाशी जी को किताब उधार दी।સુઝુકીજીએ કોબાયાશીજીને પુસ્તક ઉધાર આપ્યું.

Why: かりる = borrow (the book comes to you). かす = lend (the book goes away from you). If Kobayashi borrowed from Suzuki, then Suzuki lent to Kobayashi. The two people swap places and the verb changes. かえす (return) happens later, so it is a different meaning.
