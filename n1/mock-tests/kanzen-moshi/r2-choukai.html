1 Points — how each 聴解 question type works

聴解問題全体に共通するポイント — for every listening question (book p.11)
  • You hear the audio only once — concentrate on one item at a time. HI: ऑडियो सिर्फ़ एक बार बजता है — हर प्रश्न पर पूरा ध्यान दें। GU: ઑડિયો ફક્ત એક વાર વાગે છે — દરેક પ્રશ્ન પર પૂરું ધ્યાન આપો.
  • If you're unsure, don't linger — you'll miss the next item. HI: उलझें तो अटकें नहीं — वरना अगला प्रश्न छूट जाएगा। GU: ગૂંચવાઓ તો અટકશો નહીં — નહીં તો પછીનો પ્રશ્ન ચૂકી જશો.
  • Catch the question sentence (設問文) exactly. HI: प्रश्न-वाक्य ठीक से पकड़ें। GU: પ્રશ્ન-વાક્ય બરાબર પકડો.
  • Conversation drops subjects and objects (省略) — keep track of who does what. HI: बातचीत में कर्ता-कर्म छूट जाते हैं — कौन क्या करता है, ध्यान रखें। GU: વાતચીતમાં કર્તા-કર્મ છૂટી જાય છે — કોણ શું કરે છે, ધ્યાન રાખો.
問題1 課題理解 — what will someone do (next / first)? (p.11)

EN: Flow: question → look at options → situation + question → talk → question again → answer. Typical: 〜はこの後、どうしますか／何をしなければなりませんか. Listen for what is missing or not yet done; the other speaker often denies or partly changes a suggestion.   HI: क्रम: प्रश्न → विकल्प देखें → स्थिति + प्रश्न → बातचीत → फिर प्रश्न → उत्तर। ध्यान दें कि क्या बाक़ी है या अभी नहीं हुआ; सामने वाला अक्सर सुझाव को नकारता या थोड़ा बदलता है।   GU: ક્રમ: પ્રશ્ન → વિકલ્પ જુઓ → સ્થિતિ + પ્રશ્ન → વાતચીત → ફરી પ્રશ્ન → ઉત્તર. ધ્યાન આપો કે શું બાકી છે કે હજી નથી થયું; સામેની વ્યક્તિ ઘણી વાર સૂચનને નકારે કે થોડું બદલે છે.

問題2 ポイント理解 — reason, feeling, the "most" ~ (p.11)

EN: Flow: question → read the options (about 20 seconds) → talk → question → answer. Typical: 〜は「何が／どうして…」と言っていますか, 「最も〜は何だ」. Follow the talk with the first question as your guide, and note whose view it is (man or woman, senior or junior).   HI: क्रम: प्रश्न → विकल्प पढ़ें (लगभग 20 सेकंड) → बातचीत → प्रश्न → उत्तर। पहले सुने प्रश्न को आधार बनाकर बात का क्रम पकड़ें, और देखें कि राय किसकी है।   GU: ક્રમ: પ્રશ્ન → વિકલ્પ વાંચો (આશરે 20 સેકન્ડ) → વાતચીત → પ્રશ્ન → ઉત્તર. પહેલાં સાંભળેલા પ્રશ્નને આધારે વાતનો ક્રમ પકડો, અને જુઓ કે મત કોનો છે.

問題3 概要理解 — the gist (p.12)

EN: Nothing is printed: situation → talk → question → options. Typical: 〜は何について話していますか／話のテーマは何ですか／〜はどう考えていますか. Listen for "what about / what theme / what is the speaker getting at"; small details matter little.   HI: कुछ छपा नहीं: स्थिति → बात → प्रश्न → विकल्प। "किस बारे में / कौन-सा विषय / वक्ता क्या कहना चाहता है" पर ध्यान दें; बारीक ब्योरे कम मायने रखते हैं।   GU: કશું છપાયેલું નથી: સ્થિતિ → વાત → પ્રશ્ન → વિકલ્પ. "શેના વિશે / કયો વિષય / વક્તા શું કહેવા માગે છે" પર ધ્યાન આપો; ઝીણી વિગતો ઓછી મહત્ત્વની છે.

問題4 即時応答 — the right quick reply (p.12)

EN: Mostly workplace exchanges, so learn common short set phrases. Phrases of thanks and apology appear in both right and wrong options — know exactly which situation each belongs to.   HI: ज़्यादातर दफ़्तर की बातचीत, इसलिए आम छोटे वाक्यांश सीखें। धन्यवाद और माफ़ी के वाक्य सही और ग़लत दोनों विकल्पों में आते हैं — हर एक किस स्थिति का है, यह जानें।   GU: મોટે ભાગે ઑફિસની વાતચીત, એટલે સામાન્ય નાના વાક્યપ્રયોગો શીખો. આભાર અને માફીના પ્રયોગો સાચા અને ખોટા બંને વિકલ્પોમાં આવે છે — દરેક કઈ સ્થિતિનો છે તે જાણો.

問題5 統合理解 — comparing several pieces of information (p.12)

EN: Situation → talk (a three-way conversation, or one speaker + two listeners discussing it) → question → options. Take notes on who holds which position or opinion.   HI: स्थिति → बात (तीन लोगों की बातचीत, या एक वक्ता + दो सुनने वाले) → प्रश्न → विकल्प। कौन किस पक्ष या राय का है, इसके नोट्स लें।   GU: સ્થિતિ → વાત (ત્રણ જણની વાતચીત, કે એક વક્તા + બે શ્રોતા) → પ્રશ્ન → વિકલ્પ. કોણ કયા પક્ષ કે મતનું છે, તેની નોંધ લો.

問題1 — 課題理解 (例 + 1–6) CD2 · Tracks 02–09

問題1では、まず質問を聞いてください。それから話を聞いて、問題用紙の1から4の中から、最もよいものを一つ選んでください。Mondai ichi de wa, mazu shitsumon o kiite kudasai.
