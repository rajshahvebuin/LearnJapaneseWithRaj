Notes
Adverbs that look alike but split by meaning: 一挙に (one big change) / 一斉に (many at once) / 一気に (in one go); 隈なく (every corner) / ことごとく (every single one, usually bad) / 根こそぎ (roots and all). Main exam traps: 元来 = it was so from the start and still is, while 本来 compares the ideal with the present (key note). 密かに can be one person's secret act; 極秘で／内々に are secrets kept among a group (key note). くれぐれも is a request to someone else, not a description of your own habit.

Warm-up · ❶ ウォーミングアップ

次のうち正しいのはどれ？…… a 皿の中のものを隈なく食べた。 b 友人全員に隈なく手紙を書いた。 c 部屋の中を隈なく探した。Tsugi no uchi tadashii no wa dore? … a Sara no naka no mono o kumanaku tabeta. b Yuujin zen'in ni kumanaku tegami o kaita. c Heya no naka o kumanaku sagashita.EN: Which of these is correct? a "I ate everything on the plate kumanaku." b "I wrote kumanaku to all my friends." c "I searched every corner of the room." · HI: इनमें से कौन-सा सही है? a थाली की हर चीज़ "कुमानाकु" खा ली। b सब दोस्तों को "कुमानाकु" चिट्ठी लिखी। c कमरे का कोना-कोना छान मारा। · GU: આમાંથી કયું સાચું છે? a થાળીની બધી વસ્તુ "કુમાનાકુ" ખાઈ ગયો. b બધા મિત્રોને "કુમાનાકુ" પત્ર લખ્યો. c ઓરડાનો ખૂણેખૂણો શોધી વળ્યો.

Key (別冊 p.17): c — 部屋の中を隈なく探した。Heya no naka o kumanaku sagashita. 隈なく means "leaving no corner unchecked", so it fits searching a space, not eating or writing to people (our explanation).
