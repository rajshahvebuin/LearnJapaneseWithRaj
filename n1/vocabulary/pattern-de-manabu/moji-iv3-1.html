ヒント (summary, not the book's text)

EN: Words containing a long sound ending in ウ (コウ・ゴウ・キョウ・ソウ・ジュウ・ジョウ・シュウ・ショウ・トウ・ドウ・ホウ・ボウ・フウ・ヨウ・リョウ) are easily confused with words that have the short sound. Sort out whether there is a ウ or not, and learn the words in pairs.

HI: ウ पर ख़त्म होने वाली लंबी ध्वनि (コウ・ゴウ・キョウ・ソウ・ジュウ・ジョウ・シュウ・ショウ・トウ・ドウ・ホウ・ボウ・フウ・ヨウ・リョウ) वाले शब्द छोटी ध्वनि वाले शब्दों से आसानी से उलझ जाते हैं। ウ है या नहीं, यह साफ़ करके शब्दों को जोड़ियों में याद करें।

GU: ウ પર પૂરા થતા લાંબા અવાજ (コウ・ゴウ・キョウ・ソウ・ジュウ・ジョウ・シュウ・ショウ・トウ・ドウ・ホウ・ボウ・フウ・ヨウ・リョウ)વાળા શબ્દો ટૂંકા અવાજવાળા શબ્દો સાથે સહેલાઈથી ગૂંચવાય છે. ウ છે કે નહીં તે સ્પષ્ટ કરીને શબ્દોને જોડીમાં યાદ રાખો.

3 Confusion Pairs / Nuance Notes

The tested pairs — same consonants, differing only in a long う:

FormMeaningKey differenceUse when
車高 / 車庫shakou / shakovehicle height / garage高 コウ (long) vs 庫 コ (short).Q1, Q2
誇張 / 好調kochou / kouchouexaggeration / good form誇 コ (short) vs 好 コウ (long).Q3
傾向 / 稽古keikou / keikotendency / practice向 コウ vs 古 コ.Q4
喪失 / 素質soushitsu / soshitsuloss / aptitude喪 ソウ vs 素 ソ.Q5, Q6
失踪 / 質素shissou / shissodisappearance / frugal踪 ソウ vs 素 ソ.Q7, Q8
井戸 / 異動・移動ido / idouwell / transfer, movementShort いど vs long いどう.Q14
Exam trap — 問題Ⅱ: the question is about hiragana, so the answer is a different word with the same sound (自己 → 事故, 反抗 → 犯行). The pair partner from the list (判子, 感度, 金庫) is always there as a distractor, one う too short or too long.
Exam trap — voicing and っ as well: 意図 いと vs 井戸 いど, 実効 じっこう vs 時効 じこう — check every mark, not only the long vowel.
