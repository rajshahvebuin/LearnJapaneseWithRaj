1 Points — the meaning table (p.98)

ヒント — reminder (summary, not the book's text)

EN: Learn near-synonyms in meaning groups. Many words in the 全く…ない and かならず groups only appear with a negative or a particular sentence ending — learn those partners too. The 例題 is on III ①.

HI: मिलते-जुलते शब्दों को अर्थ-समूहों में याद करें। 全く…ない और かならず समूह के कई शब्द केवल नकारात्मक या किसी ख़ास वाक्य-अंत के साथ आते हैं — उन साथियों को भी याद करें।

GU: સરખા અર્થના શબ્દોને અર્થ-જૂથોમાં યાદ રાખો. 全く…ない અને かならず જૂથના ઘણા શબ્દો માત્ર નકાર કે ચોક્કસ વાક્ય-અંત સાથે જ આવે છે — એ સાથીઓ પણ યાદ રાખો.

2 Every question — 問題Ⅰ・Ⅱ (p.99)

問題Ⅰ　次の文の＿＿の部分に入れるのに最も適当なものを、1・2・3・4から一つ選びなさい。Mondai I: Tsugi no bun no ＿＿ no bubun ni ireru no ni mottomo tekitou na mono o, 1・2・3・4 kara hitotsu erabinasai. EN: Choose the most suitable word for the blank. HI: रिक्त स्थान के लिए सबसे उपयुक्त शब्द चुनें। GU: ખાલી જગ્યા માટે સૌથી યોગ્ય શબ્દ પસંદ કરો.

(1)

彼女は3人姉妹の末っ子なので性格が（　）している。Kanojo wa sannin shimai no suekko na node seikaku ga (　) shite iru.

3 Confusion Pairs / Nuance Notes

The "not at all" and "from before" groups are where the questions hit hardest:

かねがね / 前もって / あらかじめ / 一足先にkanegane / maemotte / arakajime / hitoashi saki ni all "beforehand" かねがね = a long-held feeling or knowledge; 前もって／あらかじめ = an action done in advance; 一足先に = going ahead of others. かねがね思っていた (Q9) · 前もって予約する
うやむや / あやふや / 漠然とuyamuya / ayafuya / bakuzen to all "vague" うやむや = a matter left unsettled (often on purpose); あやふや = an answer or memory that is unreliable; 漠然と = a vague feeling or idea. うやむやにする (Q4) · あやふやな返事
よそよそしい / 水くさい / 素っ気ないyosoyososhii / mizukusai / sokkenai all "cold, distant" よそよそしい = acting like a stranger; 水くさい = not confiding in a close friend (the complaint itself: 水くさいなあ); 素っ気ない = curt reply or attitude. 友だちなのによそよそしい (Q10)
おっとり / のんびり / のほほんottori / nonbiri / nohohon all "relaxed" おっとり = gentle, unhurried personality (praise); のんびり = relaxed situation or person; のほほん = carefree in a careless way (criticism). おっとりした性格 (Q1) · のんびり過ごす
Exam trap — negative-only adverbs: とんと, 毛頭, 皆目, ゆめゆめ, 二度と, 金輪際 all need a negative, so the questions offer three of them together. Use the verb (見ない / 思わない / わからない / 来ない) to choose.
Exam trap — shared sound, different word: よそよそしい vs よそ行き (Q10), and 上向く (improve) vs 上の空 (absent-minded) in the same table. Check the whole word, not only the first part.
