1 Points — the look-alike kanji list

ヒント — reminder (summary, not the book's text)

EN: Learn look-alike, same-sound kanji inside whole compound words, and make sure of the ones that appear in only one or two compounds. The 例題 for this pattern is on II-1 ①.

HI: एक जैसे दिखने और सुनाई देने वाले कांजी को पूरे संयुक्त शब्दों के साथ याद करें, और जो केवल एक-दो शब्दों में आते हैं उन्हें पक्का कर लें। इस पैटर्न का 例題 II-1 ① पर है।

GU: સરખા દેખાતા અને સંભળાતા કાંજીને આખા સંયુક્ત શબ્દો સાથે યાદ રાખો, અને જે ફક્ત એક-બે શબ્દોમાં આવે છે તેમને પાકા કરી લો. આ પેટર્નનું 例題 II-1 ① પર છે.

2 Every question — 問題Ⅰ (p.33)

問題Ⅰ　次の文の言葉の＿＿の部分は、どのような漢字を書きますか。同じ漢字を使うものを、1・2・3・4から一つ選びなさい。Mondai I: Tsugi no bun no kotoba no ＿＿ no bubun wa, dono you na kanji o kakimasu ka. Onaji kanji o tsukau mono o, 1・2・3・4 kara hitotsu erabinasai. EN: Which kanji is the underlined part written with? Choose the option that uses the same kanji. HI: रेखांकित हिस्सा किस कांजी से लिखा जाता है? वही कांजी वाला विकल्प चुनें। GU: રેખાંકિત ભાગ કયા કાંજીથી લખાય? એ જ કાંજીવાળો વિકલ્પ પસંદ કરો.

(1)

パーティーのしょうたい状を書く。Paatii no shoutaijou o kaku.

Full sentence: パーティーの招待状を書く。Paatii no shoutaijou o kaku. — target kanji: 招 (しょう)
EN: I write the party invitations.
HI: मैं पार्टी के निमंत्रण-पत्र लिखता हूँ।
GU: હું પાર્ટીનાં આમંત્રણ-પત્રો લખું છું.
OptionOption sentence → kanjiEnglishHindiGujarati
1先輩に会社をしょうかいしてもらう。→ 紹介Senpai ni kaisha o shoukai shite morau.I have a senior colleague introduce (紹介) me to a company.सीनियर से किसी कंपनी से परिचय करवाता हूँ।સિનિયર પાસે કોઈ કંપની સાથે પરિચય કરાવું છું.
2スポーツ大会のしょうちに力を注ぐ。→ 招致Supootsu taikai no shouchi ni chikara o sosogu.To put effort into bidding to host (招致) a sports event.खेल-प्रतियोगिता की मेज़बानी पाने में ज़ोर लगाना।રમત-સ્પર્ધાનું યજમાનપદ મેળવવામાં જોર લગાવવું.

Answer 2 (book key, 別冊 p.2). (added, not in book) 招待 and 招致 share 招 (扌 hand: beckoning someone in). 召集 is the closest trap: 召 alone also means "summon", but it has no hand radical. 紹 (糸) and 照 (灬) complete the set.

Answer 3 (book key, 別冊 p.2). (added, not in book) 噴水 and 噴出 share 噴 (口: something spouting from an opening). 墳 (土 earth → mound) and 憤 (忄 heart → anger) share 賁. 興奮's 奮 is a different shape (大 + 隹 + 田).

3 Confusion Pairs / Nuance Notes

Each set shares a sound part; the meaning part tells them apart. These are the sets the six questions test, plus other look-alikes from the list that are easy to mix up:

FormMeaningKey differenceUse when
招 / 召 / 紹 / 照 / 昭shou invite / summon / introduce / shine / bright 扌 → invite (as a host); bare 召 → summon by authority; 糸 → introduce; 灬 → light, compare; 日 → era name. 招待・招致 (Q1) · 召集 · 紹介 · 参照 · 昭和
喝 / 褐 / 渇katsu shout / brown / thirst 口 mouth → shout, cheer; 衤 → brown (cloth colour); 氵 → lack of water. 喝采・一喝 (Q2) · 褐色 · 渇水・枯渇
噴 / 墳 / 憤fun spout / mound / anger 口 → gush out; 土 → burial mound; 忄 → indignation. 噴水・噴出 (Q3) · 古墳 · 憤激
輸 / 愉 / 諭yu transport / pleasant / admonish 車 → carry; 忄 → pleasant feeling; 言 → teach, admonish. 輸出・運輸 (Q4) · 愉快 · 教諭
徐 / 除 / 叙jo slowly / remove / describe 彳 → going slowly; 阝 → remove; 又 → narrate. 徐行・徐々 (Q5) · 削除 · 叙述
生 / 性 / 牲 / 姓sei life / nature / sacrifice / surname Bare 生 → life; 忄 → inner nature; 牛 → sacrifice; 女 → family name. 学生・生活 (Q6) · 適性 · 犠牲 · 姓名
獲 / 穫kaku catch / harvest 犭 animal → catch (prey, prizes); 禾 grain → harvest crops. 獲得 · 収穫
偶 / 隅 / 遇guu chance, pair / corner / meet 亻 → chance, spouse; 阝 → corner; 辶 → meeting, treatment. 偶然 · 一隅 · 待遇
過 / 渦 / 禍ka pass / whirlpool / disaster 辶 → pass; 氵 → whirlpool (渦中 = in the thick of it); 礻 → misfortune. 通過 · 渦中 · 禍根
Exam trap — same sound, different family: on this page the book adds distractors that sound right but are not in the shape family at all: 活発 (かっ, Q2), 興奮 (ふん, Q3), 石油 (ゆ, Q4), 助手 (じょ, Q5). If an option's kanji does not share the sound part, you can rule it out quickly.
Exam trap — 召 vs 招: both mean "call". 召 (召集, 召還) is calling people in by authority (the state, the army, a company); 招 (招待, 招致) is inviting someone as a guest or bringing something in. Q1 tests exactly this.
