1 Points — the look-alike kanji list

ヒント — reminder (summary, not the book's text)

EN: Learn look-alike, same-sound kanji inside whole compound words, and make sure of the ones that appear in only one or two compounds. The 例題 for this pattern is on II-1 ①.

HI: एक जैसे दिखने और सुनाई देने वाले कांजी को पूरे संयुक्त शब्दों के साथ याद करें, और जो केवल एक-दो शब्दों में आते हैं उन्हें पक्का कर लें। इस पैटर्न का 例題 II-1 ① पर है।

GU: સરખા દેખાતા અને સંભળાતા કાંજીને આખા સંયુક્ત શબ્દો સાથે યાદ રાખો, અને જે ફક્ત એક-બે શબ્દોમાં આવે છે તેમને પાકા કરી લો. આ પેટર્નનું 例題 II-1 ① પર છે.

2 Every question — 問題Ⅰ (p.35)

問題Ⅰ　次の文の言葉の＿＿の部分は、どのような漢字を書きますか。同じ漢字を使うものを、1・2・3・4から一つ選びなさい。Mondai I: Tsugi no bun no kotoba no ＿＿ no bubun wa, dono you na kanji o kakimasu ka. Onaji kanji o tsukau mono o, 1・2・3・4 kara hitotsu erabinasai. EN: Which kanji is the underlined part written with? Choose the option that uses the same kanji. HI: रेखांकित हिस्सा किस कांजी से लिखा जाता है? वही कांजी वाला विकल्प चुनें। GU: રેખાંકિત ભાગ કયા કાંજીથી લખાય? એ જ કાંજીવાળો વિકલ્પ પસંદ કરો.

3 Confusion Pairs / Nuance Notes

Each set shares a sound part; the meaning part tells them apart. These are the sets the six questions test, plus other look-alikes from the list that are easy to mix up:

FormMeaningKey differenceUse when
歓 / 勧 / 観kan joy / urge / view 欠 open mouth → joy, cheering; 力 → push someone (recommend, recruit); 見 → look. 歓迎・歓声 (Q1) · 勧誘 · 主観
調 / 彫chou prepare, tune / carve 言 + 周 → arrange, prepare (調理, 新調); 周 + 彡 → carve (彫刻). 調理・新調 (Q2) · 彫像
峡 / 狭 / 挟kyou gorge / narrow / pinch 山 → gorge, strait; 犭 → narrow; 扌 → squeeze between. 海峡・峡谷 (Q3) · 狭小 · 挟撃
頑 / 願 / 顔gan stubborn / wish / face All end in 頁 (head). Left part 元 → stubborn; 原 → wish, apply; 彦 → face. 頑固・頑強 (Q4) · 願書 · 顔面
謙 / 兼 / 嫌ken humble / both / dislike 言 → humble speech; bare 兼 → do two things at once; 女 → dislike. 謙譲・謙虚 (Q5) · 兼任 · 嫌悪
壊 / 懐kai break / bosom, nostalgia 土 → collapse, destroy; 忄 → heart (懐中 = "in the breast pocket", 懐かしい). 決壊・壊滅 (Q6) · 懐中電灯
裁 / 栽 / 載sai judge / plant / load Same frame 𢦏; inside: 衣 cloth (cut → judge), 木 tree (plant), 車 vehicle (load, publish). 裁判 · 栽培・盆栽 · 記載・搭載
弊 / 幣hei harm / money Same top 敝; bottom 廾 → harm, exhaustion; 巾 cloth → offering, money. 弊害・疲弊 · 貨幣・紙幣
概 / 慨gai outline / lament 木 → general outline (概略, 概要); 忄 → emotion (感慨, 慨嘆). 概略 · 感慨
堤 / 提tei embankment / submit 土 → embankment; 扌 → hold up, present. 堤防 (Q6 sentence) · 提出
Exam trap — two groups with the same reading: this list has two カン groups (観・歓・勧 and 換・喚) and two キョウ groups (挟・峡・狭 and 境・鏡). Q1 and Q3 mix options from both groups, so knowing only the sound is not enough; check the shape family.
Exam trap — homophones of everyday words: きょうだい in Q3 is 鏡台 (dressing table), not 兄弟; かいだん in Q6 is 怪談 (ghost story), not 階段. The rest of the option sentence (化粧品, ビデオ) tells you which word is meant.
