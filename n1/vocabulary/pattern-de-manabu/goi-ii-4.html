1 Points — look-alike adverbs (p.90)

ヒント — what pattern II tests (summary, not the book's text)

EN: Many N1 adverbs come in families that look almost the same: すらっと／ずらっと, ふかふか／ぶかぶか／ぷかぷか. A single dakuten (゛) or handakuten (゜) changes the meaning completely. Learn each one inside its example phrase so that the sound and the scene stick together. (The pattern's own 例題 is on p.84, which is not in the scan.)

HI: N1 के कई क्रिया-विशेषण ऐसे परिवारों में आते हैं जो लगभग एक जैसे दिखते हैं: すらっと／ずらっと, ふかふか／ぶかぶか／ぷかぷか। एक दाकुतेन (゛) या हान्दाकुतेन (゜) अर्थ पूरी तरह बदल देता है। हर शब्द को उसके उदाहरण-वाक्यांश के साथ याद करें ताकि ध्वनि और दृश्य साथ-साथ याद रहें।

GU: N1 ના ઘણા ક્રિયાવિશેષણો એવા પરિવારોમાં આવે છે જે લગભગ સરખા દેખાય છે: すらっと／ずらっと, ふかふか／ぶかぶか／ぷかぷか. એક દાકુતેન (゛) કે હાન્દાકુતેન (゜) અર્થ સંપૂર્ણ બદલી નાખે છે. દરેક શબ્દને તેના ઉદાહરણ-વાક્યાંશ સાથે યાદ રાખો જેથી અવાજ અને દૃશ્ય સાથે યાદ રહે.

問題Ⅰ　次の文の＿＿の部分に入れるのに最も適当なものを、1・2・3・4から一つ選びなさい。Mondai I: Tsugi no bun no ＿＿ no bubun ni ireru no ni mottomo tekitou na mono o, 1・2・3・4 kara hitotsu erabinasai. 3 Confusion Pairs / Nuance Notes

These are the look-alike sets the ten questions turn on, plus the other dakuten pairs from the list:

FormMeaningKey differenceUse when
こうこうと / ごうごうとkoukou to / gougou to blazing bright / roaring Light vs sound. こうこう (煌々) is for lamps; ごうごう (轟々) is for rivers, wind, flames. 灯りがこうこうと · 川がごうごうと (Q10)
しっくり / じっくりshikkuri / jikkuri fits well / carefully, slowly しっくり is a result (things fit, people get on); じっくり is the manner of doing (looking, thinking, simmering — see II ⑤ Q6). しっくりいかない · じっくり見る
すらっと / ずらっとsuratto / zuratto slender / in a row One body (tall and slim) vs many things lined up. すらっと伸びた手足 · ずらっと並ぶ
するする / ずるずるsurusuru / zuruzuru smoothly / dragging on Unvoiced = light, quick, easy; voiced = heavy, sliding, never-ending. するする登る · ずるずる休む
ふかふか / ぶかぶか / ぷかぷかfukafuka / bukabuka / pukapuka fluffy / too loose / floating ふ bed or bread, ぶ shoes or clothes that are too big, ぷ things bobbing on water or in air. ふかふかのベッド · ぶかぶかの靴 · ぷかぷか浮かぶ (Q7)
はらはら / ばらばら / ぱらぱらharahara / barabara / parapara anxious / in pieces / sprinkling はら a feeling; ばら things (or people) scattered or disunited; ぱら light scattered drops, pages flipping. はらはらしながら · ばらばらの部品 (Q6) · 雨がぱらぱら
ぼつぼつ / ぽつぽつbotsubotsu / potsupotsu about time to begin / sparsely ぼつぼつ = "let's slowly get started"; ぽつぽつ = dots appearing here and there (people, rain). ぼつぼつ始めよう · ぽつぽつとしか来ない
どっぷり / とっぷりdoppuri / toppuri soaked in (a lifestyle) / (sun) fully set どっぷり浸かる is figurative immersion; とっぷり暮れる is only for nightfall. 安易な生活にどっぷり · 日がとっぷり暮れた
まちまち / めいめい / べつべつmachimachi / meimei / betsubetsu varied / each person / separately まちまち = the set is not uniform; めいめい = each individual (does X); べつべつ = apart from each other. 日によってまちまち (Q8) · めいめいが持つ · 別々に包む
近々 / 着々 / 転々 / 点々chikajika / chakuchaku / tenten / tenten soon / steadily / moving about / dotted 近々 is time and takes no と; the other three are manner adverbs with と. 転々 and 点々 sound identical. 近々オープン (Q9) · 着々と進む · 転々と移り住む · 点々と跡
