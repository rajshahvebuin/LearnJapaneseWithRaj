2 Every question — 問題Ⅰ・Ⅱ (p.23)

問題Ⅰ — choose the reading

次の文の＿＿をつけた言葉は、どのように読みますか。その読み方を、それぞれの1・2・3・4から一つ選びなさい。Tsugi no bun no ＿＿ o tsuketa kotoba wa, dono you ni yomimasu ka. Sono yomikata o, sorezore no 1・2・3・4 kara hitotsu erabinasai. EN: How is each underlined word read? Choose from 1–4. HI: हर रेखांकित शब्द कैसे पढ़ा जाता है? 1–4 में से चुनें। GU: દરેક રેખાંકિત શબ્દ કેવી રીતે વંચાય? 1–4માંથી પસંદ કરો.

問1 — (1)

教会の厳かなムードに、思わず目が潤んだ。Kyoukai no ogosoka na muudo ni, omowazu me ga urunda.

EN: The solemn mood of the church brought tears to my eyes before I knew it.
HI: चर्च के गंभीर माहौल में अनायास ही मेरी आँखें नम हो गईं।
GU: ચર્ચના ગંભીર વાતાવરણમાં અજાણતાં જ મારી આંખો ભીની થઈ ગઈ.
OptionReadingEnglishHindiGujarati
1はれやかhareyaka晴れやか = cheerful, brightप्रसन्नપ્રસન્ન
2ひそやかhisoyaka密やか = quiet, secretचुपचापછાનું
3おごそかogosoka厳か = solemnगंभीरગંભીર
4しめやかshimeyakasolemn and quiet (funerals)शांत और उदासશાંત અને ગમગીન

Answer 3 (book key, 別冊 p.2). (added, not in book) 厳 + か = おごそか (厳かな雰囲気). しめやか also means "solemn" and fits the meaning, but it is never written 厳か; that is the trap.

3 Confusion Pairs / Nuance Notes

Okurigana settles most of these. The table lists the sets the questions test and the places where okurigana alone is not enough:

FormMeaningKey differenceUse when
勝つ / 勝るkatsu / masaru win / be superior In the て-form both are written 勝って, so the okurigana does not help. かつ is winning an event. まさる compares and says one is better (AよりBが勝る). 試合に勝つ · 兄のほうが勝っている (Q8)
交じる / 混じるmajiru mix in (distinct) / blend 交じる: the parts stay separate (people in a group, kanji and kana). 混じる: things blend into one (liquids, colours). 外国人に交じって (Q9) · 雑音が混じる
初めて / 始めてhajimete for the first time / starting 初めて is an adverb ("first time"). 始めて is the て-form of 始める and needs an object or a following verb. 〜のは初めて (Q10) · 仕事を始めて
治す / 直すnaosu cure / repair, correct 治す is for bodies (illness, injury). 直す is for things and mistakes. 傷を治す (Q14) · 時計を直す
治る / 治めるnaoru / osameru heal / govern る → なおる, める → おさめる. Same kanji, unrelated meanings. 病気が治る · 国を治める (Q7)
試す / 試みるtamesu / kokoromiru test / attempt す → ためす (try something out to see if it works). みる → こころみる (attempt something difficult; more formal). 力を試す · 手術を試みる (Q13)
厳しい / 厳かkibishii / ogosoka strict / solemn しい → きびしい. か → おごそか. 厳しい訓練 (Q12) · 厳かな雰囲気 (Q1)
後 (あと / のち / うしろ) · 後れるato / nochi / ushiro / okureru after / later (formal) / behind / lag ろ → うしろ, れる → おくれる. With no okurigana: あと in speech, のち in formal writing and forecasts. 考え方が後れる (Q4) · 雨のち曇り
上 (うえ / うわ / かみ)ue / uwa / kami above / upper, outer / upstream うえ stands alone. うわ appears in compounds (上着, 上履き). かみ is "upper side" in set words (川上, 風上). 机の上 · 上着 · 川上
Exam trap — two real kanji for one reading: in 問題Ⅱ, Q9 (交じる vs 混じる) and Q10 (初めて vs 始めて) offer two real words with the same sound. Grammar decides Q10 (adverb vs verb); nuance decides Q9 (people stay distinct → 交).
Exam trap — meaning-alike readings: しめやか (Q1), かかわらない (Q3), すぐれて (Q8) and つらなって (Q6) all fit the sentence's meaning, but none is a reading of the kanji shown. Always check: "Is this reading actually used with this kanji?"
