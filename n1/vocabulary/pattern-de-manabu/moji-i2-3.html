ヒント — reminder (summary, not the book's text)

EN: Look at the okurigana first; if it does not decide the reading, use the meaning of the sentence. The 例題 for this pattern are on I-2 ①.

HI: पहले ओकुरिगाना देखें; अगर उससे उच्चारण तय न हो, तो वाक्य के अर्थ से तय करें। इस पैटर्न के 例題 I-2 ① पर हैं।

GU: પહેલાં ઓકુરિગાના જુઓ; જો તેનાથી ઉચ્ચાર નક્કી ન થાય, તો વાક્યના અર્થ પરથી નક્કી કરો. આ પેટર્નના 例題 I-2 ① પર છે.

2 Every question — 問題Ⅰ・Ⅱ (p.25)

問題Ⅰ — choose the reading

次の文の＿＿をつけた言葉は、どのように読みますか。その読み方を、それぞれの1・2・3・4から一つ選びなさい。Tsugi no bun no ＿＿ o tsuketa kotoba wa, dono you ni yomimasu ka. Sono yomikata o, sorezore no 1・2・3・4 kara hitotsu erabinasai. EN: How is each underlined word read? Choose from 1–4. HI: हर रेखांकित शब्द कैसे पढ़ा जाता है? 1–4 में से चुनें। GU: દરેક રેખાંકિત શબ્દ કેવી રીતે વંચાય? 1–4માંથી પસંદ કરો.

問1 — (1)

自分の行いを省みて、先生に教えを請う。Jibun no okonai o kaerimite, sensei ni oshie o kou.

EN: Reflecting on my own conduct, I ask my teacher for guidance.
HI: अपने आचरण पर आत्मचिंतन करके, मैं शिक्षक से मार्गदर्शन माँगता हूँ।
GU: પોતાના વર્તન પર આત્મચિંતન કરીને, હું શિક્ષક પાસે માર્ગદર્શન માગું છું.
OptionReadingEnglishHindiGujarati
1こころみてkokoromite試みて = trying — not a reading of 省कोशिश करके — 省 का उच्चारण नहींપ્રયત્ન કરીને — 省નો ઉચ્ચાર નથી
2かえりみてkaerimite省みる = to reflect on oneselfआत्मचिंतन करनाઆત્મચિંતન કરવું
3うしろみてushiromitenot a standard wordमानक शब्द नहींમાન્ય શબ્દ નથી
4はぶみてhabumitenot a word (省く is はぶく)शब्द नहींશબ્દ નથી

Answer 2 (book key, 別冊 p.2). (added, not in book) 省 + みる = かえりみる (自分を省みる in the list). 省 + く would be はぶく; option 4 wrongly glues はぶ- onto -みる.

問1 — (2)

自分の行いを省みて、先生に教えを請う。Jibun no okonai o kaerimite, sensei ni oshie o kou.

EN: (same sentence) … I ask my teacher for guidance.
HI: (वही वाक्य) … शिक्षक से मार्गदर्शन माँगता हूँ।
GU: (એ જ વાક્ય) … શિક્ષક પાસે માર્ગદર્શન માગું છું.
OptionReadingEnglishHindiGujarati
1とうtou問う = to ask (a question) — not a reading of 請पूछना — 請 का उच्चारण नहींપૂછવું — 請નો ઉચ્ચાર નથી
2いうiu言う = to sayकहनाકહેવું
3こうkou請う = to beg, ask forयाचना करनाયાચના કરવી
4さそうsasou誘う = to inviteन्योता देनाઆમંત્રણ આપવું

Answer 3 (book key, 別冊 p.2). (added, not in book) 請 + う = こう; 教えを請う is a set phrase ("ask to be taught"). 請 + ける would be うける (仕事を請ける). とう (問う) is a meaning-alike trap.

問2 — (3)

3 Confusion Pairs / Nuance Notes

In this pattern one kanji carries several readings. The okurigana usually tells you which one; where it cannot, meaning decides. These are the sets the questions test, plus the ones most likely to trip you up:

FormMeaningKey differenceUse when
優れる / 優しいsugureru / yasashii excel / kind -れる → すぐれる; -しい → やさしい. Ability vs character. 優れた科学者 (Q3) · 優しい父親 (Q4)
頼む / 頼る / 頼もしいtanomu / tayoru / tanomoshii ask / rely on / reliable The adjective comes from たの(む), not たよ(る). 先生に頼む · 親を頼る · 頼もしい人 (Q7)
速い / 速やかhayai / sumiyaka fast / prompt The stem changes: はや + い, but すみ + やか. 速度が速い · 速やかに申し出る (Q6)
怠ける / 怠るnamakeru / okotaru be lazy / neglect 怠ける is general laziness; 怠る is failing to do a specific duty (努力・注意を怠る). 怠ける人 (Q9) · 努力を怠る
断る / 断つkotowaru / tatsu refuse / cut off -る → ことわる (say no to someone); -つ → たつ (cut a habit or tie). お断り (Q10) · 酒を断つ
弾く / 引くhiku play (instrument) / pull Same sound; 弾く only for playing an instrument (ピアノ・ギター). ピアノを弾く (Q12) · 綱を引く
冷える / 冷める / 冷たい / 冷やかすhieru / sameru / tsumetai / hiyakasu get cold / cool down / cold / tease 冷える = becomes cold (beer, body). 冷める = something hot loses heat (soup, passion). 冷やかす is figurative: tease. ビールが冷える · スープが冷める
明るい / 明らか / 明らむakarui / akiraka / akaramu bright / obvious / grow light あか- in most forms, but あき- in 明らか. 明るい性格 · 明らかな事実 · 空が明らむ
端 (はし / はた / は)hashi / hata / ha edge No okurigana: はし is the everyday word; はた is "beside" water or a road; は survives in fixed phrases like 山の端. 部屋の端 · 池の端 · 山の端
Exam trap — same okurigana, different stem: 問題Ⅰ gives four 〜しい options for 優しい (Q4), four 〜やか options for 速やか (Q6), and 問題Ⅱ four 〜みて options for 染みて (Q14). When the okurigana is shared, the okurigana cannot help; you must know the stem of that kanji.
Exam trap — on-reading turned into a verb: ゆうれた (優 = ゆう), らいもしい (頼 = らい) and はややか mix a reading of the kanji with the wrong ending. A kun-reading stem never comes from the on-reading, so these drop out at once.
