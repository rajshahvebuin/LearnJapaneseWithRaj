4日目 — 伴う・狂う・誓う (Tomonau, Kuruu, Chikau)

Source

Theme
動詞① (verbs, set 1) — the book's own list is organized by the verb's final kana/okurigana: う-verbs, then く-verbs, then ぐ-verbs on page 1, then す-verbs on page 2. That verb-ending pattern is the real organizing principle this day, so the groups below follow it directly.

Notes

Q1

記者が取材のため、事件現場に（　）。Kisha ga shuzai no tame, jiken genba ni (___).

Full sentence: 記者が取材のため、事件現場に赴いた。...jiken genba ni omomuita.
EN: The reporter proceeded to the crime scene to gather information.
HI: रिपोर्टर जानकारी जुटाने के लिए घटनास्थल पर गया।
GU: રિપોર્ટર માહિતી મેળવવા ઘટનાસ્થળે ગયો.
OptionJapaneseEnglishHindiGujarati
a驚いたodoroitawas shocked (wrong — no movement implied)(यहाँ ग़लत रूप)(અહીં ખોટું સ્વરૂપ)

3 Confusion Pairs / Nuance Notes

Today's traps are mostly about matching the right verb to the right kind of object — every 練習Ⅰ question above turns on exactly this:

FormMeaningKey differenceUse when
履くhaku To put on (footwear, trousers) Object goes on the legs/feet. "Put on shoes/pants."
敷くshiku To lay down flat (on the floor) Object is spread out beneath something/someone. "Lay out a futon/cushion."
損なうsokonau To harm, damage, spoil Object is a condition (health, mood) that gets worse. "Spoil someone's mood," "harm one's health."
賄うmakanau To cover, manage (costs/resources) Object is money, food supply, or logistics. "Cover expenses with the budget."
慕うshitau To adore, long for An emotional attachment to a person. "Look up to/adore a senior."
誓うchikau To swear, pledge A solemn declaration/promise. "Swear to God," "pledge loyalty."
Exam trap: 履く vs 敷く is the most testable pair — both are everyday "put something down/on" verbs, but 履く is strictly for the legs/feet (shoes, trousers, socks) while 敷く is for spreading something flat beneath a person or object (a cushion, a futon, a sheet). Mixing them up is a very common beginner-to-intermediate error that N1 questions exploit.
