3 Confusion pairs — the traps in the wrong options

Every wrong option above is one of the four trap types from the tips page (see 漢字読み①). These are the ones worth remembering (added, not in book):

FormMeaning / readingKey difference
災害saigai / 被害higai / 加害kagai disaster / damage suffered / inflicting harm Same 害 = ガイ; only the first kanji changes. 災 = サイ.
規模kibo vs 模型mokei scale vs model 模 = ボ in 規模, モ in 模型・模様・模範.
根底kontei / 根本konpon / 根元nemoto foundation / basis / base of a stem Three real words with 根 — read the second kanji: 底 テイ, 本 ホン→ポン, 元 もと.
覆うoou vs 覆すkutsugaesu to cover vs to overturn Same kanji, two kun-yomi — the okurigana (う / す) decides.
裁判saiban vs 判断handan trial vs judgement 判 = バン after 裁 (and in 評判 ひょうばん); ハン at the start of a word.
訴訟soshou そしょう ✓ / しょそう ✗ Don't swap the syllables: 訴 ソ comes first.
堤tei vs 是ze embankment vs right / correct 堤 contains 是 but is read テイ (堤防).
待ち遠しいmachidooshii まちどおしい ✓ / まちどうしい ✗ 遠い = とおい (お-spelling) + rendaku → どおしい.
把握haaku vs 掌握shouaku grasp, awareness vs control, command Both end in 握 アク; 把 = ハ, 掌 = ショウ.
破裂haretsu vs 破壊hakai bursting vs destruction Same 破 = ハ; 裂 = レツ, 壊 = カイ.
Exam trap: four questions in this drill (災害, 根底, 把握, 破裂) offered a different real word that shares one kanji with the answer — 被害, 根本, 掌握, 破壊. Knowing that a reading is a real word is not enough; check that it is the word written with both of these kanji.
