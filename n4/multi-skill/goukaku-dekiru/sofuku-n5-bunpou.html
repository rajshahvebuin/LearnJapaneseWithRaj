もんだい1 「正しい文法」の文 — what goes in the ( )? (p.168–169)

（　　）に 何を 入れますか。１・２・３・４から いちばん いい ものを 一つ えらんで ください。( ) ni nani o iremasu ka. 1・2・3・4 kara ichiban ii mono o hitotsu erande kudasai.

EN: What do you put in the ( )? Choose the best one from 1–4.   HI: ( ) में क्या रखेंगे? 1–4 में से सबसे सही एक चुनें।   GU: ( ) માં શું મૂકશો? 1–4 માંથી સૌથી યોગ્ય એક પસંદ કરો.   (れい: 毎朝 パン（　）食べます → 3 を.)

総復習 [1]

木（　　）いすを 作ります。Ki ( ) isu o tsukurimasu.

EN: I make a chair out of wood.
HI: लकड़ी से कुर्सी बनाते हैं।
GU: લાકડામાંથી ખુરશી બનાવું છું.
OptionJapaneseEnglishHindiGujarati
1をo(object)(कर्म) को(કર્મ) ને
2がga(subject)(कर्ता)(કર્તા)

Answer 4 (別冊 p.6). Why: the material you make something from takes で: 木で 作る. The object is already いすを, so を cannot be used again.
