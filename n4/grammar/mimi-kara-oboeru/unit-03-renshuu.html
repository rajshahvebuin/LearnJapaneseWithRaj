2 Quiz / Exercise Section

I　（　）にひらがなを1字ずつ書きなさい。 (Write one hiragana in each ( ).)

I-1 · point 23

このアパートは駅から遠い（　）（　）、家賃が高い。Kono apaato wa eki kara tooi ( )( ), yachin ga takai.

このアパートは駅から遠いのに、家賃が高い。Kono apaato wa eki kara tooi noni, yachin ga takai.

EN: This apartment is far from the station, yet the rent is high.
HI: यह अपार्टमेंट स्टेशन से दूर है, फिर भी किराया ज़्यादा है।
GU: આ ઍપાર્ટમેન્ટ સ્ટેશનથી દૂર છે, છતાં ભાડું વધારે છે.

Book answer (解答 p.2): のに. Why: far from the station should mean cheap; high rent is the opposite → のに. ので would make "high because far", which is illogical. Point 23, p.29.

I-2 · points 27, 20

どんな味（　）する（　）、食べてみました。Donna aji ( ) suru ( ), tabete mimashita.

どんな味がするか、食べてみました。Donna aji ga suru ka, tabete mimashita.

EN: I tried eating it to see what it tasted like.
HI: कैसा स्वाद है, यह जानने के लिए खाकर देखा।
GU: કેવો સ્વાદ છે, તે જાણવા ખાઈ જોયું.

Book answer (解答 p.2): が、か. Why: 味がする (point 27); どんな is a question word, so the clause ends in か (point 20). CD sentence, p.30.

I-3 · point 19

あした、晴れる（　）どう（　）、心配です。Ashita, hareru ( ) dou ( ), shinpai desu.

あした、晴れるかどうか、心配です。Ashita, hareru ka dou ka, shinpai desu.

EN: I'm worried about whether it will be sunny tomorrow.
HI: कल धूप निकलेगी या नहीं, इसकी चिंता है।
GU: કાલે તડકો નીકળશે કે નહીં, તેની ચિંતા છે.

Book answer (解答 p.2): か、か. Why: the set form かどうか. Point 19, p.27.

I-4 · point 22

雨にぬれた（　）（　）、かぜをひいてしまいました。Ame ni nureta ( )( ), kaze o hiite shimaimashita.

雨にぬれたので、かぜをひいてしまいました。Ame ni nureta node, kaze o hiite shimaimashita.

EN: I got wet in the rain, so I caught a cold.
HI: बारिश में भीग गया, इसलिए सर्दी लग गई।
GU: વરસાદમાં ભીંજાઈ ગયો, એટલે શરદી થઈ ગઈ.

Book answer (解答 p.2): ので. Why: getting wet naturally causes a cold → reason ので. Point 22 example 2, p.28.

I-5 · point 21

天気予報（　）よると、あしたは一日雨だそうです。Tenki yohou ( ) yoru to, ashita wa ichinichi ame da sou desu.

天気予報によると、あしたは一日雨だそうです。Tenki yohou ni yoru to, ashita wa ichinichi ame da sou desu.

EN: According to the weather forecast, it will rain all day tomorrow.
HI: मौसम समाचार के अनुसार कल पूरे दिन बारिश होगी।
GU: હવામાન સમાચાર મુજબ કાલે આખો દિવસ વરસાદ પડશે.

Book answer (解答 p.2): に. Why: the source phrase is N によると. Point 21 注意, p.28.

II　（　）のことばを適当な形にして＿＿に書きなさい。 (Put the word in ( ) into the right form and write it on the line.)

II-1 · point 25

「このセーターを、ちょっと＿＿＿＿みてもいいですか」（きる）"Kono seetaa o, chotto ____ mite mo ii desu ka." (kiru)

「このセーターを、ちょっときてみてもいいですか」"Kono seetaa o, chotto kite mite mo ii desu ka."

EN: "May I try this sweater on?"
HI: "क्या यह स्वेटर थोड़ा पहनकर देख सकता हूँ?"
GU: "શું આ સ્વેટર જરા પહેરી જોઉં?"

Book answer (解答 p.2): きて. Why: みる follows the て-form; きる (wear) is group II → きて. Point 25, p.30.

II-2 · point 26

「このコップは＿＿＿＿やすいですから、注意してください」（われる）"Kono koppu wa ____ yasui desu kara, chuui shite kudasai." (wareru)

「このコップはわれやすいですから、注意してください」"Kono koppu wa ware-yasui desu kara, chuui shite kudasai."

EN: "This cup breaks easily, so please be careful."
HI: "यह गिलास आसानी से टूट जाता है, इसलिए ध्यान रखिए।"
GU: "આ ગ્લાસ સહેલાઈથી તૂટી જાય છે, એટલે ધ્યાન રાખજો."

Book answer (解答 p.2): われ. Why: ます-stem: われます → われ + やすい. Point 26, p.30.

II-3 · point 19

これは初めて作った料理です。＿＿＿＿かどうかわかりません。（おいしい）Kore wa hajimete tsukutta ryouri desu. ____ ka dou ka wakarimasen. (oishii)

これは初めて作った料理です。おいしいかどうかわかりません。Kore wa hajimete tsukutta ryouri desu. Oishii ka dou ka wakarimasen.

EN: This is the first time I've made this dish. I don't know whether it's good.
HI: यह पहली बार बनाया खाना है। पता नहीं स्वादिष्ट है या नहीं।
GU: આ પહેલી વાર બનાવેલી વાનગી છે. ખબર નથી સ્વાદિષ્ટ છે કે નહીં.

Book answer (解答 p.2): おいしい. Why: い-adjectives go straight before かどうか in the plain form. Point 19, p.27.

II-4 · points 22, 6

あしたは＿＿＿＿ので、ゆっくり＿＿＿＿と思います。（日よう日／休む）Ashita wa ____ node, yukkuri ____ to omoimasu. (nichiyoubi / yasumu)

あしたは日よう日なので、ゆっくり休もう（／休める）と思います。Ashita wa nichiyoubi na node, yukkuri yasumou (/ yasumeru) to omoimasu.

EN: Tomorrow is Sunday, so I'm thinking of having a good rest. (休める: so I think I'll be able to rest.)
HI: कल रविवार है, इसलिए आराम करने की सोच रहा हूँ। (休める: इसलिए लगता है आराम कर पाऊँगा।)
GU: કાલે રવિવાર છે, એટલે આરામ કરવાનું વિચારું છું. (休める: એટલે લાગે છે આરામ કરી શકીશ.)

Book answer (解答 p.2): 日よう日な、休もう／休める. Why: noun + な + ので (point 22). Then two answers are accepted: volitional 休もう + と思います = my plan (point 6), or potential 休める + と思います = "I think I can rest" (point 2).

II-5 · point 20

「パンダは何を＿＿＿＿か、知っていますか」（食べる）"Panda wa nani o ____ ka, shitte imasu ka." (taberu)

「パンダは何を食べるか、知っていますか」"Panda wa nani o taberu ka, shitte imasu ka."

EN: "Do you know what pandas eat?"
HI: "क्या आप जानते हैं पांडा क्या खाते हैं?"
GU: "શું તમે જાણો છો પાંડા શું ખાય છે?"

Book answer (解答 p.2): 食べる. Why: plain form before the embedded か. Point 20, p.27.

II-6 · point 24

うっかりして、電車の中にかさを＿＿＿＿しまいました。（わすれる）Ukkari shite, densha no naka ni kasa o ____ shimaimashita. (wasureru)

うっかりして、電車の中にかさをわすれてしまいました。Ukkari shite, densha no naka ni kasa o wasurete shimaimashita.

EN: I carelessly left my umbrella on the train.
HI: लापरवाही से छतरी ट्रेन में ही भूल गया।
GU: બેધ્યાનપણે છત્રી ટ્રેનમાં જ ભૂલી ગયો.

Book answer (解答 p.2): わすれて. Why: しまう follows the て-form. Point 24 ②, p.29.

II-7 · point 23

お金を＿＿＿＿のに、どうして商品が届かないのだろう。（はらう）Okane o ____ noni, doushite shouhin ga todokanai no darou. (harau)

お金をはらったのに、どうして商品が届かないのだろう。Okane o haratta noni, doushite shouhin ga todokanai no darou.

EN: I paid, so why hasn't the item arrived?
HI: पैसे दे दिए, फिर भी सामान क्यों नहीं पहुँचा?
GU: પૈસા ચૂકવ્યા, છતાં સામાન કેમ નથી પહોંચ્યો?

Book answer (解答 p.2): はらった. Why: paying already happened → past plain はらった + のに. Point 23 example 2, p.29.

II-8 · point 26

この本は専門のことばが多くて＿＿＿＿にくい。（わかる）Kono hon wa senmon no kotoba ga ookute ____ nikui. (wakaru)

この本は専門のことばが多くてわかりにくい。Kono hon wa senmon no kotoba ga ookute wakari-nikui.

EN: This book has a lot of technical words, so it's hard to understand.
HI: इस किताब में तकनीकी शब्द बहुत हैं, इसलिए समझना मुश्किल है।
GU: આ પુસ્તકમાં પારિભાષિક શબ્દો ઘણા છે, એટલે સમજવું અઘરું છે.

Book answer (解答 p.2): わかり. Why: ます-stem わかり + にくい. Point 26, p.30.

II-9 · point 21

テイさんの話によると、アリさんはとても歌が＿＿＿＿そうです。（じょうず）Tei-san no hanashi ni yoru to, Ari-san wa totemo uta ga ____ sou desu. (jouzu)

テイさんの話によると、アリさんはとても歌がじょうずだそうです。Tei-san no hanashi ni yoru to, Ari-san wa totemo uta ga jouzu da sou desu.

EN: According to Tei, Ali is a very good singer.
HI: तेई के कहने के अनुसार अली बहुत अच्छा गाते हैं।
GU: તેઈના કહેવા મુજબ અલી ખૂબ સારું ગાય છે.

Book answer (解答 p.2): じょうずだ. Why: hearsay そうだ keeps だ after a な-adjective. Writing じょうず alone would make the "looks like" そうだ (point 36). Point 21, p.28.

II-10 · point 21

リンさんは子どものころ、サッカーの選手に＿＿＿＿そうです。（なりたい）Rin-san wa kodomo no koro, sakkaa no senshu ni ____ sou desu. (naritai)

リンさんは子どものころ、サッカーの選手になりたかったそうです。Rin-san wa kodomo no koro, sakkaa no senshu ni naritakatta sou desu.

EN: I hear Lin wanted to be a football player when she was a child.
HI: सुना है लिन बचपन में फ़ुटबॉल खिलाड़ी बनना चाहती थीं।
GU: સાંભળ્યું છે કે લિન બાળપણમાં ફૂટબૉલ ખેલાડી બનવા માગતી હતી.

Book answer (解答 p.2): なりたかった. Why: 子どものころ = past, so なりたい → なりたかった (い-adjective past). Point 21 example 1, p.28.

II-11 · points 4, 20

夏休みに旅行＿＿＿＿つもりです。でもまだ、どこに＿＿＿＿か決めていません。（する／行く）Natsuyasumi ni ryokou ____ tsumori desu. Demo mada, doko ni ____ ka kimete imasen. (suru / iku)

夏休みに旅行するつもりです。でもまだ、どこに行くか決めていません。Natsuyasumi ni ryokou suru tsumori desu. Demo mada, doko ni iku ka kimete imasen.

EN: I plan to travel in the summer holidays. But I haven't decided where to go yet.
HI: गर्मी की छुट्टियों में घूमने का इरादा है। पर अभी तय नहीं किया कहाँ जाऊँ।
GU: ઉનાળાની રજાઓમાં ફરવાનો વિચાર છે. પણ હજી નક્કી નથી કર્યું ક્યાં જવું.

Book answer (解答 p.2): する、行く. Why: つもり takes the dictionary form (point 4); どこに … か takes the plain form (point 20, example 4, p.27).

III　正しいものに○をつけなさい。 (Circle the correct one.)

III-1 · point 26

このボールペンは書きにくいから、もう使いたくありません。Kono boorupen wa kaki-nikui kara, mou tsukaitaku arimasen.

EN: This ballpoint pen is hard to write with, so I don't want to use it any more.
HI: इस बॉलपेन से लिखना मुश्किल है, इसलिए अब इस्तेमाल नहीं करना चाहता।

Book answer (解答 p.2): にくい. Why: "don't want to use it any more" only makes sense if it is hard to write with. Point 26.

III-2 · point 26

EN: "It's snowing. The roads are slippery, so be careful."
HI: "बर्फ़ गिर रही है। रास्ता फिसलन भरा है, ध्यान रखिए।"
GU: "બરફ પડે છે. રસ્તો લપસણો છે, ધ્યાન રાખજો."

Book answer (解答 p.2): やすい. Why: snow + "be careful" → the road slips easily. Point 26.

III-3 · point 26

EN: My grandmother says, "This book has big letters, so it's easy to read."

Book answer (解答 p.2): やすい. Why: big letters → easy to read (compare point 26 example 2).

III-4 · points 22–23

HI: अभी अप्रैल ही है, फिर भी आज बहुत गर्मी है।

3 Confusion Pairs / Nuance Notes

Half of this 練習 is ので vs のに and か vs かどうか:

FormMeaningConnectionKey differenceUse when
〜ので~node because N な／V・adj + ので Expected result; any sentence can follow (plans too). III-5, III-7, III-12.
〜のに~noni even though N な／V・adj + のに Unexpected fact only; no plan / guess / advice after it. III-4, III-6, IV-2, IV-5.
〜からです~kara desu it's because plain + からです The only one of these that can end a sentence. IV-6.
疑問詞 … かgimonshi … ka what / where … どこ・何時 + plain + か Question word present. III-8, III-10.
〜かどうか~ka dou ka whether or not plain + かどうか No question word. III-9.
〜たそうです~ta sou desu I hear it happened V-た + そうです Tense goes on the verb, never on そう (× そうでした). IV-4.
Exam trap: when のに is in the question, scan the options for つもり, だろう, 〜う(と思う), ほうがいい or 〜てください — they are all wrong after のに. The correct option is always a plain fact, often with てしまう.
