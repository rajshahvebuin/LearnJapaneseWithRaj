Notes
This lesson starts a new idea: kanji built from parts (組み合わせ漢字). The opener page explains the four positions a part can take. The book gives each kanji's readings, stroke count, a picture of how its parts combine, and 2–4 words, with English, Korean and Portuguese. The Hindi and Gujarati, the romaji, every "Why" note and §3 are added by us. We describe the book's pictures in words; they are not reproduced.
must-learn = a word the book shades grey. In Part 1, shaded words are N5 words; learn these first.
電11話 = the small number is the lesson where the other kanji is taught (電・会・今 → Lesson 11).
Katakana reading = 音読み (on-yomi) · Hiragana reading = 訓読み (kun-yomi). A hyphen (はな-す) separates the kanji's part from the okurigana.
Every kanji here is made of two or three parts, e.g. 言 (word) + 舌 (tongue) = 話 (speak).

練習1 Q11

日本語で 新聞を 読みたいです。Nihongo de shinbun o yomitai desu.

EN: I want to read newspapers in Japanese.
HI: मैं जापानी में अख़बार पढ़ना चाहता हूँ।
GU: મારે જાપાનીમાં છાપું વાંચવું છે.
Book answer (解答 p.261, P89)Romaji
にほんご・しんぶん・よ（みたい）nihongo · shinbun · yo(mitai)

Why: 聞 in 新聞 is ぶん (on reading ブン), not きく. 読みたい = 読む + たい (want to), so 読 = よ.

Why: 休みの日 = "a day off": 日 alone after の is ひ. 休日 (きゅうじつ) means the same, but here the words are separate. 何 before を is なに (Lesson 5).

父の しゅみは 読書です。Chichi no shumi wa dokusho desu.

EN: My father's hobby is reading.
HI: मेरे पिताजी का शौक़ पढ़ना है।
GU: મારા પિતાનો શોખ વાંચન છે.
Book answer (解答 p.261, P89)Romaji
ちち・どくしょchichi · dokusho

Why: 父 (Lesson 5) = ちち for your own father. 読書 = どく (on reading of 読) + しょ (書, Lesson 9).

練習1 Q14

練習1 Q15

3 Confusion Pairs / Nuance Notes

Combination kanji share parts, so the traps are same frame, different inside (間／聞／門) and same left side, different right (話／読／語).

FormMeaningKey difference
間aida / kan / 聞kiku / bun between / listen
HI: बीच / सुनना · GU: વચ્ચે / સાંભળવું		 Both are 門 + something. 日 inside = 間; 耳 inside = 聞. Both are in 新聞 vs. 時間 — easy to swap.
話hanasu / 読yomu / 語go speak / read / language
HI: बोलना / पढ़ना / भाषा · GU: બોલવું / વાંચવું / ભાષા		 All start with 言. Right side: 舌 (tongue) → speak, 売 (sell) → read, 吾 (I) → language.
買うkau / 貝kai buy / shellfish (Lesson 7)
HI: ख़रीदना / सीप · GU: ખરીદવું / છીપ		 買 = 罒 (net) on top of 貝 (shell = old money).
休yasumu / 体karada rest / body
HI: आराम / शरीर · GU: આરામ / શરીર		 (added, not in book) 体 (Part 2) is 亻 + 本: one more line at the bottom of 木.
時toki / ji / 時間jikan / 時計tokei time, when / time / clock
HI: समय, जब / समय / घड़ी · GU: સમય, જ્યારે / સમય / ઘડિયાળ		 とき alone; じ with numbers (4時 よじ) and in 時間; と in 時計 only.
一週間isshuukan / 来週raishuu / 先週senshuu / 今週konshuu one week / next week / last week / this week
HI: एक हफ़्ता / अगले / पिछले / इस हफ़्ते · GU: એક અઠવાડિયું / આવતા / ગયા / આ અઠવાડિયે		 週 is always しゅう (long う). Before it, いち becomes いっ.
道michi / 水道suidou / 書道shodou road / water supply / calligraphy
HI: रास्ता / जल आपूर्ति / सुलेख · GU: રસ્તો / પાણી પુરવઠો / સુલેખન		 みち alone; どう (long う) in words.
Most testable point: 間 (sun inside the gate) vs. 聞 (ear inside the gate). 時間 じかん, 一週間 いっしゅうかん use 間; 聞く, 新聞 しんぶん use 聞. In 表記 questions, look inside the 門.
