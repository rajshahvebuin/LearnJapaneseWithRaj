練習Ⅰ — choose the correct option

Q1

フォントを（a. 変更　b. 移動）する。Fonto o (a. henkou / b. idou) suru.

Full sentence: フォントを変更する。Fonto o henkou suru.
EN: To change the font.
HI: फ़ॉन्ट बदलना।
GU: ફોન્ટ બદલવો.
OptionJapaneseEnglishHindiGujarati
a変更henkouchangingबदलनाબદલવો
b移動idoumoving (fits カーソル, not フォント)(यहाँ ग़लत रूप)(અહીં ખોટું સ્વરૂપ)

Why: フォントを変更する ("to change the font") is the fixed collocation; 移動する ("to move") pairs with カーソル (カーソルを移動する) in this day's vocabulary, not with フォント.

Q2

文字のサイズは10ポイントに（a. 設定　b. 選択）してください。Moji no saizu wa juu pointo ni (a. settei / b. sentaku) shite kudasai.

Full sentence: 文字のサイズは10ポイントに設定してください。Moji no saizu wa juu pointo ni settei shite kudasai.
EN: Please set the font size to 10 points.
HI: कृपया फ़ॉन्ट का आकार 10 पॉइंट पर सेट करें।
GU: કૃપા કરીને ફોન્ટનું કદ 10 પોઈન્ટ પર સેટ કરો.
OptionJapaneseEnglishHindiGujarati
a設定setteisettingसेट करनाસેટ કરવું
b選択sentakuselecting (fits 範囲, not a numeric size value)(यहाँ ग़लत रूप)(અહીં ખોટું સ્વરૂપ)

Why: 文字のサイズを設定する ("to set the font size") is the fixed collocation for assigning a numeric value; 選択する ("to select") pairs with 範囲 (a range/area), not with setting a specific point size.

Q3

「これよりさっきのほうがよかったから、（a. 元にもどそう　b. 保存しよう）。」"Kore yori sakki no hou ga yokatta kara, (a. moto ni modosou / b. hozon shiyou)."

Full sentence: 「これよりさっきのほうがよかったから、元にもどそう。」"Kore yori sakki no hou ga yokatta kara, moto ni modosou."
EN: "The way it was before was better than this, so let's undo it."
HI: "पहले वाला इससे बेहतर था, तो इसे पूर्ववत कर लेते हैं।"
GU: "પહેલાંનું આના કરતાં સારું હતું, તો પૂર્વવત્ કરી લઈએ."
OptionJapaneseEnglishHindiGujarati
a元にもどそうmoto ni modosoulet's undo/revert itपूर्ववत कर लेते हैंપૂર્વવત્ કરી લઈએ
b保存しようhozon shiyoulet's save it (would lock in the worse version, contradicting the complaint)(यहाँ ग़लत रूप)(અહીં ખોટું સ્વરૂપ)

Why: Preferring how it was "before" (さっきのほうがよかった) calls for undoing the change (元にもどす); saving (保存する) would lock in the current, less-preferred version instead.

GU: આ ફોટો પર ક્લિક કરવાથી, તમે તેને મોટો કરી શકો છો.

3 Confusion Pairs / Nuance Notes

Today's exercises hinge on matching the right verb to the right object in word-processing commands — exactly what Q1, Q2, and Q7 above test. Compare them:

FormMeaningKey differenceUse when
フォントを変更するfonto o henkou suru To change the font 変更 pairs with typeface choice. Switching from 明朝 to ゴシック.
カーソルを移動するkaasoru o idou suru To move the cursor 移動 pairs with the cursor's position. Moving the insertion point.
サイズを設定するsaizu o settei suru To set the size 設定 pairs with assigning a specific numeric value. "Set the font to 10pt."
範囲を選択するhan'i o sentaku suru To select a range 選択 pairs with picking out an area/extent, not a fixed value. Highlighting text before formatting it.
元にもどすmoto ni modosu To undo Reverts to the state before the last change. "That was better before — undo it."
保存するhozon suru To save Locks in the current state as-is. Finishing an edit you want to keep.
Collocation trap: 下線／アンダーラインをつける ("add an underline") uses つける specifically because 下線 is treated as something "attached" to text; you cannot use つける the same way with フォント or ペースト — each formatting noun in this day's vocabulary has its own fixed verb partner (変更する for フォント, 設定する for サイズ, つける for 下線/アンダーライン), and mixing them up is the exact trap 練習Ⅱ Q8 sets.
